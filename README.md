# Personal Portfolio & Student Blog

A responsive multi-page personal portfolio and student blog website built with HTML5 and CSS3.

The website showcases my background, projects, learning journey, certifications, interests, and contact information.

## Pages

- **Home** — Introduction and current focus
- **About Me** — Learning journey, skills, interests, and certifications
- **Projects** — Selected software and technology projects
- **Blog** — Reflections on software engineering and technology
- **Contact** — Contact information and contact form

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design

## Features

- Responsive multi-page layout
- Persistent sidebar navigation
- Project showcase
- Certification section
- Blog section
- Contact form
- GitHub and LinkedIn links
- Mobile-friendly design
